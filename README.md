# 🌿 FarmFlow | Agricultural Management System

**FarmFlow** is a high-performance, AI-integrated management platform designed for modern agriculture. Built with a **React** frontend and a **Django** backend, it utilizes the **Base44 SDK** to bridge fieldwork with digital intelligence.

---

## 🎨 The Aesthetic: Stone & Forest
The application follows a custom-designed visual language:
* **Primary:** Forest Green (`#1B4332`)
* **Secondary:** Harvest Gold (`#D4A373`)
* **Background:** Natural Stone (`#FEFAE0`)

## 🚀 Key Features
* **AI Weather Hub:** Real-time climate data with agronomic advice powered by Gemini.
* **Field & Livestock Tracking:** Interactive management of farm assets.
* **Financial Ledger:** Integrated bookkeeping with automated currency formatting.
* **Task Engine:** High-performance fieldwork checklist with real-time updates.

## 💻 Local Development

### Prerequisites
1.  **Clone the Repo:** `git clone [your-repo-url]`
2.  **Install Dependencies:** `npm install`
3.  **Environment Setup:** Create a `.env.local` file in the root directory.

### Configuration (`.env.local`)
```env
VITE_BASE44_APP_ID=your_app_id
VITE_BASE44_APP_BASE_URL=your_django_backend_url
